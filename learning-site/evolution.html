Self-Harness: Harnesses That Improve Themselves

手工调 harness 追不上模型迭代，于是把「改进」本身变成一个可审计的状态转移：失败签名、最小提案，再在没见过的题上回归。

  • B 论文精读
  • 7 个章节
  • 正文待 WU-4 填充

章节地图

  1. 问题：手工调 harness 追不上模型迭代为什么需要让工装自己进化。
  2. 把「改进」变成一个可审计的状态转移谁提出、谁验证、谁记账。
  3. Weakness Mining：把失败变成可复用的机制聚类失败签名，而不是逐条打补丁。
  4. Harness Proposal：多样，但每个都最小提案如何既发散又可评估。
  5. Proposal Validation：held-in / held-out 双边回归用没见过的题防止自欺。
  6. 证据：三个模型都涨了提升来自哪里，代价是什么。
  7. 边界与批判什么能自动改，什么仍然需要人。

WU-4 将填充：三步闭环的细节、实验数据、定性差异，以及阶段 0 报告里可复用的关键发现。
